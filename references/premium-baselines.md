# 五种高端基准风格

本组从用户提供的五张演示总览图中提炼版式规律。总览图足以判断配色、密度、层级与翻页节奏，不代表掌握原稿中的字体文件、完整正文或制作工具。这里提供重新编排的可编辑模板，不收录原截图、原作者姓名、Logo、肖像、二维码、机构履历或未经验证的数据。不要猜测或写入原稿使用的模型名称。

## 两层作用

它们是五种独立可选风格，也是用户没有指定风格时的保底模板组。保底意味着选取一个合适的完整范本，沿用其排版纪律，不意味着每页套同一种布局。

1. 用户明确指定鲸格原有风格、新风格、品牌规范或提供参考，优先执行。
2. 修改已有演示时延续其已选风格，除非用户要求改风格。不要把现有 IR 的主题悄悄改掉。
3. 新建演示且未指定风格，按下表选模板。场景仍不明时用咨询简报。
4. 先确定讲给谁听、供现场讲还是会后阅读，再决定密度。读物不要硬套大字舞台，短讲不要塞进报告表格。

机器可读规则：[`templates/style-routing.json`](../templates/style-routing.json)。设计令牌见 [`DESIGN.md`](../DESIGN.md) 第 8 节。

| 场景 | 名称 / ID | 视觉支点 | 页面节奏 |
|---|---|---|---|
| 咨询、研究、经营汇报、比较分析、场景不明 | 咨询简报 / `premium-consulting` | 白底、墨色宋体标题、陶土红强调、细横线、证据与结论对齐 | 结论封面 → 证据 → 时间线 → 比较表 → 优先级 → 行动 → 指标 → 决策 |

## 所有保底模板共同守住的标准

- 先写一句本页要让观众相信的结论，再决定用表格、图表、流程、图像还是一句话。不把段落拆成三个同尺寸圆角卡片就当设计完成。
- 一页一个主视觉焦点。标题、正文、注释形成明确的三个层级；强调色只指向关键结论或关键数据。
- 16:9 模板按 1600×900 建模：常规横向安全区约 96px、纵向约 64px。大标题约 96px，普通标题约 48px，正文约 22px，注释约 14px。中文标题优先在语义边界断行；避免落单字、挤到页边或用极细字承担投影正文。
- 报告页允许较高密度，但同类信息沿同一基线排列；缩小正文不是解决拥挤的首选。拆页、改成表格或把细节移到备注。
- 舞台页保留大块留白；连续两三页同构时重新检查节奏。单句页、证据页、机制页、章节页各有用途，禁止把所有页都做成封面。
- 数据必须有单位、口径与来源；条形图从零起算并保持一致比例。模板中“演示数据”只是版式样例，使用时替换为用户数据或删除。不得把示例数字当成事实。
- 默认不开连续动画，不使用无语义的光圈、漂浮几何、霓虹渐变、玻璃卡片或通用机器人填空。若用户明确选择原有赛博、玻璃、电影等风格，遵守那套风格自己的规则；仍检查文字可读性和信息层级。
- 图片承担证据、产品或叙事任务时才加入。不要为了“高级”强塞配图；不把 CSS 场景当照片。真实图片继续执行原有图片能力分流和 1–10 图构图规则。
- 学参考的比例、秩序与节奏，不复制身份元素。匿名示例不填虚构作者；用户自己的署名和品牌，只有在用户提供或明确要求时才加入。

## 使用与适配

每套完整模板位于 `templates/full-decks/<ID>/`，包含 8 页、`content-ir.json`、`index.html`、`styles.css`、`deck.js`。主题令牌位于 `templates/themes/<ID>.css`。共享布局和放映逻辑位于 `templates/full-decks/_shared/premium-core.css` 与 `premium-runtime.js`。

复制模板时一并复制对应主题与共享文件，并更新相对路径。不要只复制 HTML。也可保留模板目录层级后直接打开。新系列支持本地文件和 HTTP 预览；无需构建工具、在线字体或外部脚本。

结构与颜色不能互相替代：换到另一主题后还要选择适合其密度和叙事的页面。保留本页的可编辑 DOM、`data-editable`、稳定 `data-field` 和 `aside.notes`。含分行或强调标记的文字会被运行时拆成稳定的可编辑片段，保存时保留分行结构。`content-ir.json` 是可维护源稿，任何最终修改需回写到对应 IR 字段；浏览器“导出修改”包含以 `slide-id:field[:part-N]` 为键的文字覆盖和逐页版式参数，不应冒充完整 IR。

共享运行时：方向键 / PageUp / PageDown 翻页，Home / End 首尾，S 讲者备注，E 文字编辑，Escape 退出编辑或备注。编辑模式的“版式”面板可调整当前页左右留白、上下留白和内容间距，并单独恢复本页版式；文字和版式都在浏览器保存，支持导出 JSON。复杂布局通过有语义的类与 CSS 令牌调整；打印显示全部页并保留颜色。手机采用纵向阅读，不把桌面画布缩成不可读的小图。改变内容或版式后需重新检查是否溢出。

当某一任务需要原有手势、复杂影像或更丰富编辑面板时，接入原有功能模块；本系列不自动申请相机权限。

## 交付门槛

逐页看缩略图判断整套节奏，再放大查标题断行、图表标注和正文。检查 1280px 桌面、768px 平板与 375px 手机；至少操作一次翻页、讲者备注、编辑保存、导出和打印。确认无原参考身份信息、无示例数字冒充事实、无截图充当页面、无缺失资源。未通过时修对应模板或内容结构，不靠添加装饰掩盖问题。

风格命名：`premium-product` 的显示名称为“雷军版”，`premium-minimal` 为“乔布斯”；原来的“产品发布”“极简舞台”保留为兼容别名。风格名称可以使用这些公开称呼，不加入参考素材原作者的署名或品牌。
